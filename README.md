# ВайбкодКлавиатура

Небольшая Android IME-клавиатура с готовыми вайбкод-фразами. Клавиши вставляют текст в текущее поле ввода.

## Кнопки

- Continue
- Давай быстрее пж
- Че там
- я люблю клод код
- я люблю кодекс
- самое главное мэйк но мистэйкс
- Хуйня переделай
- Охуенно оставляй
- сделай трекер привычек
- удалить символ слева
- переключиться на следующую включённую клавиатуру
- вставить три пробела

## Открыть и собрать

Открой папку проекта в Android Studio и дождись синхронизации Gradle. Нужен JDK 17 и Android SDK Platform 35. Затем собери APK через меню **Build → Build APK(s)**.

После установки открой приложение и нажми **Включить клавиатуру**, затем **Выбрать клавиатуру**. Android покажет системное предупреждение для любой сторонней клавиатуры; после выбора открой поле ввода в любом приложении.

Клавиатура не использует интернет и не содержит сторонних библиотек.
